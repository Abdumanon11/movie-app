# 🎬 Movie App

A modern movie discovery web application built with HTML, CSS and JavaScript using the TMDB API.

## 🚀 Live Demo

👉 - Live Demo → `https://abdumanon11.github.io/movie-app/`
    - GitHub → `https://github.com/Abdumanon11`
## 📌 About the project

Movie App allows users to discover movies, search for specific titles, filter movies by genre and sort them by rating or title.

Each movie has a detailed modal window with additional information such as description, genres, runtime, director and cast.

Users can also add movies to their favorites. Favorites are saved in LocalStorage, so they remain available after refreshing the page.

## ✨ Features

- 🎬 Display popular movies
- 🔎 Search movies
- 🎭 Filter movies by genre
- ⭐ Sort movies by rating
- 🔤 Sort movies by title
- ❤️ Add and remove movies from favorites
- 💾 Save favorites using LocalStorage
- 📖 Detailed movie information
- 🎭 Display director and cast
- 🖼️ Movie posters and backdrops
- 📱 Responsive design
- ⏳ Loading states
- 📄 Load more movies
- ⚠️ Error handling
- 🌐 GitHub Pages deployment
