# 🎬 Movie App

A movie search application built with JavaScript and The Movie Database (TMDB) API.

## ✨ Features

- 🎬 Popular movies
- 🔎 Movie search with debounce
- 🎭 Filter movies by genre
- 📊 Sort movies by rating and title
- ➕ Load more movies
- ❤️ Add and remove movies from favorites
- 💾 Favorites saved in LocalStorage
- 🪟 Movie details modal
- 🎭 Movie cast and director information
- ⭐ Dynamic rating colors
- 📱 Responsive design for mobile and desktop
- 🌐 Russian language support

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- TMDB API
- LocalStorage
- Git & GitHub
